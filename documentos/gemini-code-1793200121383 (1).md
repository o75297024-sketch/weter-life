# Documento de Diseño de Interfaz de Usuario (UI/UX)
## Proyecto: AguaRecordatorio
**Versión:** 1.0.0  
**Estado:** Especificación de Diseño Frontend  
**Tecnologías:** HTML5, CSS3 (Custom Properties / Flexbox / Grid), JavaScript (ES6+)  

---

## 1. Introducción y Filosofía de Diseño

### 1.1 Objetivo Visual
El diseño de **AguaRecordatorio** busca transmitir **frescura, serenidad, dinamismo y claridad**. La interfaz debe priorizar la facilidad de uso mediante componentes limpios, indicadores de progreso fluidos y un contraste óptimo que facilite la lectura rápida en dispositivos móviles.

### 1.2 Enfoque de Layout
* **Mobile-First:** La interfaz está pensada para ser operada con una sola mano en pantallas de smartphones.
* **Progressive Web App (PWA):** Layout adaptable sin scrollbars innecesarias, emulando la sensación táctil de una aplicación nativa.

## 2. Sistema de Paleta de Colores

Basado en la guía de marca oficial del proyecto, se definen las variables CSS globales (`:root`) para la paleta cromática.

### 2.1 Variables CSS (`variables.css`)

```css
:root {
  /* Colores Principales / Primarios */
  --color-primary: #0094B8;        /* Azul Cyan Hidratación (Botones principales, barras de progreso) */
  --color-primary-dark: #1B7085;   /* Azul Turquesa Oscuro (Encabezados secundarios, cards activas) */
  
  /* Colores Secundarios / Superficies */
  --color-surface-dark: #214852;   /* Azul Petróleo (Contenedores de tarjetas, paneles modales) */
  --color-bg-dark: #002933;        /* Azul Profundo (Fondo principal de la aplicación) */
  --color-bg-alt: #293133;         /* Gris Oscuro Pizarra (Fondos auxiliares, barras de navegación) */

  /* Colores Estado y Feedback */
  --color-success: #2ECC71;        /* Verde (Recordatorio completado, racha lograda) */
  --color-warning: #F39C12;        /* Naranja (Recordatorio pendiente próximo a vencer) */
  --color-danger: #E74C3C;         /* Rojo (Recordatorio omitido / Error de validación) */
  
  /* Neutrales y Texto */
  --color-text-primary: #FFFFFF;   /* Texto blanco sobre fondos oscuros */
  --color-text-secondary: #B0BEC5; /* Texto secundario / Leyendas auxiliares */
  --color-border: #2C3E50;         /* Bordes de división limpios */
}
